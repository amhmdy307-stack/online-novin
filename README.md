# کافی‌نت آنلاین نوین

نسخه پایه قابل استقرار Flask برای سایت کافی‌نت آنلاین نوین.

## اجرا
```bash
pip install -r requirements.txt
python app.py
```

## ورود مدیریت
آدرس:
`/admin/login`

نام کاربری پیش‌فرض:
`admin`

رمز پیش‌فرض:
`123456`

قبل از انتشار، `ADMIN_PASSWORD` را در Render تغییر دهید.

## Render
Repository را به Render وصل کنید. `render.yaml` فرمان build/start را مشخص می‌کند.

## نکته
این نسخه اسکلت اجرایی و قابل توسعه است. اتصال واقعی درگاه بانکی، سامانه پیامکی، احراز هویت پیامکی و ذخیره فایل‌ها باید با اطلاعات سرویس‌دهنده واقعی تکمیل شود.


## پنل‌های جداگانه
- مشتری: `/customer/login` و `/customer`
- مدیریت: `/admin/login` و `/admin`
- ورود مشتری فعلاً با شماره موبایل و بدون OTP است.
- گزینه تغییر حالت ورود از پنل مدیریت طراحی شده و با اتصال سامانه پیامکی می‌توان OTP را فعال کرد.
